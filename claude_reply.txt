Penpot / Figma UI Specs Auto-Discovery Fix:

1. **Root Cause**:
   Just like the Diagram studio issue, the Screen / Penpot Specs API (`GET /api/screens`) previously only queried records registered in `.ai-manager/screens.json` (or Mongo). `.penpot.json` layout files created directly on disk in the `ui/` directory (such as `generated_hey_genrate_some_design.penpot.json`, `jeel.penpot.json`, and `modern_saas_analytics_dashboard.penpot.json`) were not automatically imported or indexed into the store.

2. **Fix Implemented**:
   - Added `syncDiskScreensToStore()` in `screenRoutes.ts` to scan the `ui/` workspace directory for any `.penpot.json` files on API list requests.
   - Unindexed `.penpot.json` files found on disk are automatically parsed and registered into `screens.json` / Mongo.

3. **Verification**:
   - All `.penpot.json` files in the `ui/` folder are now auto-indexed and visible in the Penpot Specs dropdown in the frontend Web UI.
   - Vitest suite passed cleanly (8/8 tests passed).
