## 1. MongoDB & Mongoose Removal Summary

In accordance with owner directive, **MongoDB has been removed 100% across the codebase**. The platform is fully local, single-user, and offline-first:

1. **Zero Mongoose Models**: Deleted `packages/ai-manager-web/server/models` (including `ProjectModel`, `ActivityLogModel`, `DbConnectionModel`, `DiagramModel`, `ScreenModel`).
2. **Zero MONGODB_URI**: Removed `MONGODB_URI` environment variable from both root `.env` and `packages/ai-manager-web/.env`.
3. **Zero Atlas Connections**: Stripped all connection initializers, fallback reads, and cloud writes from `server/index.ts`, `auth.ts`, `projects.ts`, `dbRoutes.ts`, `diagramRoutes.ts`, `dashboardRoutes.ts`, `screenRoutes.ts`, and `qaDiagnosticsService.ts`.
4. **Zero Dependency**: Removed `"mongoose"` from `packages/ai-manager-web/package.json`.
5. **Auth & Admin Elimination**: Completed full removal of authentication gates, `LoginPage`, `RegisterPage`, `AdminPage`, session verifications, and route guards. The application starts directly into the workspace cockpit dashboard.

## 2. Final Storage Architecture Map (Where Everything Lives)

All application persistence resides exclusively in the local `.ai-manager/` directory and per-project database files:

| Storage Location | Data Type / Domain | Content / Structure |
| :--- | :--- | :--- |
| `.ai-manager/projects.json` | Project Registry | Array of registered workspaces, root paths, GitHub repo links, branches, AST sync timestamps, and indexing status. |
| `.ai-manager/screens.json` | OpenPencil Screens Studio | ScreenLayoutSpec records: layout boards, visual component trees, design system tokens, themes, and chat history. |
| `.ai-manager/diagrams.json` | Architecture & ERD Studio | Diagram objects: Excalidraw element trees, draw.io XML sync references, viewport appState, and diagram types. |
| `.ai-manager/activity.json` | Audit Trail Logs | Chronological event logs (last 50 actions): project creation, database connections, AST index events, sync operations. |
| `.ai-manager/connections.json` | Local Database Connections | Registered database connection specs (PostgreSQL / Supabase / SQLite), encrypted connection strings. |
| `.ai-manager/credentials.enc` | Encrypted Secrets Store | AES-256-GCM encrypted local vault storing Groq/OpenAI API keys, Git PAT tokens, and webhook secrets. |
| `.ai-manager/design_tokens.json` | Design System Tokens | Color palettes, typography hierarchies, border radii, and spacing tokens for UI synthesis. |
| `.ai-manager/branch-flags.json` | Git Branch Meta | Local feature branch review flags, notes, and status markers. |
| `.ai-manager/users.json` | Local Profile | Default local desktop user record and preferences (`usr_admin_default`). |
| `.ai-manager/dbs/:projectId.sqlite` | Per-Project SQLite DB | In-process WASM SQLite relational databases created and queried per project workspace. |
| `pglite_data/:projectId/` | Per-Project PGlite Data | Embedded Postgres WASM data directory backing the Supabase Studio UI (`:8082`) and `pglite-socket` TCP server (`:5432`). |
