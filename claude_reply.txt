### 🛡️ Phased Execution Plan (Zero Build Breakage Guarantee)

Hum is restructuring ko **4 sequential phases** mein execute karenge, jisme har phase ke baad compilation check (`npx tsc --noEmit`) aur test runs execute honge:

#### Phase 1: Dead Code Pruning & Root Cleanup (First Step)
- Accidental `packages/.dbci/` delete karna.
- 11 dead `*Screen.tsx` components delete karna (`src/components/`).
- Stale server routes delete karna (`server/modules.ts`, `server/contextRoutes.ts`).
- Dead backup delete karna (`temp/screens_page_backup.tsx`).
- Duplicate `claude_reply.txt` remove karke single root copy retain karna.

#### Phase 2: Frontend Migration (`src/features/` & `src/shared/`)
- `src/features/` directory create karke subfolders banana:
  - `cockpit/` (`ProjectsPage.tsx`, components, hooks)
  - `graphify/` (canvas, drawer, hooks)
  - `db-manager/` (`DbManagerPage.tsx`, `ConnectDbModal.tsx`, `useDbManager.ts`)
  - `diagrams/` (`DiagramsPage.tsx`, `useDiagrams.ts`)
  - `screens/` (`ScreensPage.tsx`, studio subcomponents, `useScreens.ts`)
  - `qa/` (`QaPage.tsx`, `useQa.ts`)
  - `git/` (`GitViewPage.tsx`, git subcomponents, `useGit.ts`)
  - `auth/` (`LoginPage.tsx`, `RegisterPage.tsx`, `AdminPage.tsx`)
  - `settings/` (`SettingsPage.tsx`, `useSettings.ts`)
  - `dashboard/` (`DashboardPage.tsx`, `useDashboard.ts`)
  - `chat/` (scaffold for new chat)
- `src/shared/` create karke move karna:
  - `ui/` (`button`, `card`, `tabs`, `badge`, etc.)
  - `context/` (`AuthContext`, `ThemeContext`)
  - `api/` (`client.ts`)
  - `types/` (`excalidraw.d.ts`)
  - `components/Layout.tsx`
- Update all import statements in `App.tsx` and across features.
- Run `npx tsc --noEmit` to verify 0 errors.

#### Phase 3: Server Migration (`server/modules/` & `server/shared/`)
- `server/modules/` create karke routes and services migrate karna:
  - `db/` (`dbRoutes.ts`, `drivers/`)
  - `diagrams/` (`diagramRoutes.ts`)
  - `screens/` (`screenRoutes.ts`, `screenAiService.ts`, `screenDiskService.ts`, `screenTypes.ts`)
  - `qa/` (`qaRoutes.ts`, `qaDiagnosticsService.ts`, `qaAstSafetyService.ts`, `qaTestRunnerService.ts`)
  - `git/` (`gitRoutes.ts`)
  - `graphify/` (`graphifyRoutes.ts`, `graphifyService.ts`)
  - `auth/` (`auth.ts`)
  - `settings/` (`settingsRoutes.ts`)
  - `dashboard/` (`dashboardRoutes.ts`)
  - `projects/` (`projects.ts`)
  - `admin/` (`adminRoutes.ts`)
- `server/shared/` create karke move karna:
  - `middleware/` (`requireAuth`, `requireAdmin`, `localOrAuth`)
  - `utils/` (`encryption.ts`, `JsonStore.ts`, `IStore.ts`, `RuleEngine.ts`, `logger.ts`)
- Update `server/index.ts` imports and route mountings.
- Run test suite to verify 100% passing tests.

#### Phase 4: MCP Wrappers, Context Index & Chat Scaffolding
- `server/mcp/` implement karna:
  - `dbTool.ts`, `diagramTool.ts`, `screenTool.ts`, `gitTool.ts`, `qaTool.ts`.
- `server/context-index/` implement karna:
  - `indexBuilder.ts` (lightweight listing: path + 1-line summary, zero vector embeddings).
  - `indexReader.ts` (selective on-demand loader).
- `server/chat/` implement karna:
  - `chatRoutes.ts` & `agentService.ts`.
- `src/features/chat/pages/ChatPage.tsx` mount karna.
