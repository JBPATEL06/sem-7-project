# Storage Locations for Diagrams and Figma / Penpot Files

Diagrams and Figma / Penpot design files are stored in two layers (Cloud Database + Local Disk Mirror):

---

### 1. Primary Cloud Database (MongoDB Atlas)
Both are persisted in real-time to your connected MongoDB Atlas cluster (`cluster0.cgdh1pm.mongodb.net/ai_manager`):
- **Diagrams**: Stored in the `diagrams` collection (`DiagramModel`) — stores Excalidraw element trees, geometries, arrows, text, coordinates, and canvas state.
- **Figma / Penpot Screens**: Stored in the `screens` collection (`ScreenModel`) — stores design artboard specifications, component trees, layouts, geometry coordinates, fills, and styling tokens.

---

### 2. Local Workspace Disk Files (Offline & Backup Mirror)
Whenever a diagram or screen is created or updated, a mirrored backup is also written locally to the `.ai-manager` folder:
- **Diagrams File**: `packages/ai-manager-web/.ai-manager/diagrams.json`
- **Figma / Penpot Screens File**: `packages/ai-manager-web/.ai-manager/screens.json`

---

### 3. File Exports Available
- **Diagrams**: Can be downloaded as `.excalidraw` JSON files, `.png` images, or `.svg` vector files from the Diagram Studio toolbar.
- **Figma / Penpot Screens**: Can be downloaded as official Penpot Plugin Schema 2.0 JSON manifests via the **Export** button, or copied as React + Tailwind TSX code from the **Code & AST** tab.
