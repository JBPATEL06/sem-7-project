1. Dual Authentication & Account Linking Implementation Summary
Package Location: `packages/ai-manager-web`
Backend Server: Express + Local MongoDB (`mongodb://127.0.0.1:27017/ai_manager_web`)
Mongoose User Model:
- `email`: String (unique, lowercased, indexed)
- `passwordHash`: String | null (bcrypt hashed with 10 salt rounds)
- `googleId`: String | null
- `driveLinked`: Boolean (default `false`)
- `driveTokenExpiry`: Date | null

Account Linking Logic (`/api/auth/google`):
1. Queries MongoDB for existing user by lowercased `email`: `User.findOne({ email })`.
2. If account exists (e.g. originally registered via password): updates record by attaching `googleId`, setting `driveLinked = true`, and updating token expiry window.
3. If no account exists: creates new User document.
4. Issues unified JWT token signed with `JWT_SECRET`.

Strict JWT Claims Schema & Parity Guarantee:
Both `/api/auth/login`, `/api/auth/register`, and `/api/auth/google` issue identical JWT token claims:
{
  "sub": "<user_id_string>",
  "email": "<user_email>",
  "authMethod": "google" | "password",
  "iat": 1785238339,
  "exp": 1785324739 (exact 24-hour expiration)
}
