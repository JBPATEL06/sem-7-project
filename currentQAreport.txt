# Comprehensive QA Test Report & Figma Functionality Audit

---

### 1. Canvas & Visual Rendering Engine Issues

| # | Feature / Area | Observed Problem | Expected Figma / OpenPencil Behavior | Severity |
|---|---|---|---|---|
| **1.1** | **Frame Relative Coordinates & Clipping** | Child elements (gray bars, yellow circle, bottom nav) spill outside the mobile frame (`X: -10`, `X: 450`) because coordinates are treated as canvas-global rather than relative to the parent frame. | All child nodes must be positioned relative to the parent Frame origin `(0, 0)` and clipped when `clipContent: true`. | **Critical** |
| **1.2** | **Primitive Block Rendering vs Real Components** | Elements render as flat, raw solid color blocks (red header block, orange search bar, black text placeholder bars) looking unstyled. | Should render styled UI components with proper typography, rounded corners, subtle shadows, placeholder icons, and real text. | **High** |
| **1.3** | **Parent Frame Drag Synchronization** | Dragging the `Generic Mobile Home Screen` root frame moves the outer border, but unparented or absolute-positioned children lag or don't translate with the parent. | Transforming/dragging a parent frame must apply a matrix translation to all descendant children synchronously in 60fps. | **Critical** |
| **1.4** | **Double Header Bar Clutter** | Page renders two stacked header bars: the outer platform tab bar (`Dashboard / Untitled / Generic...`) and the inner studio menu bar (`File Edit View Object...`). | Studio canvas should have a clean, unified single top bar with project name, tool dock, zoom, and action buttons without double nesting. | **Medium** |

### 2. Left Sidebar (Layers, Pages & Assets)

| # | Feature / Area | Observed Problem | Expected Figma / OpenPencil Behavior | Severity |
|---|---|---|---|---|
| **2.1** | **Tab Naming** | The left sidebar tab is labeled `"File"` instead of `"Layers"`. | Figma & OpenPencil use **`Layers`** and **`Assets`** tabs. | **Medium** |
| **2.2** | **Layer Reordering** | Layer items cannot be dragged up/down in the tree to reorder z-index. | Users should be able to drag-and-drop layer items in the tree to change rendering hierarchy and reparent nodes. | **High** |
| **2.3** | **Layer Hierarchy Visual Indentation** | Deeply nested items (e.g. `HomeNavItem` inside `BottomNav`) have minimal indentation and lack collapse/expand chevron animations. | Tree view must support clear hierarchy nesting lines, collapsibility per group/frame, and distinct icons (Frame `#`, Text `T`, Vector `◇`, Group `◫`). | **Medium** |

---

### 3. Right Property Inspector

| # | Feature / Area | Observed Problem | Expected Figma / OpenPencil Behavior | Severity |
|---|---|---|---|---|
| **3.1** | **Auto-Layout Section Missing** | No controls for Flex/Auto-Layout (Direction: Horizontal `→` / Vertical `↓`, Gap, Padding X/Y, Align items). | When a Frame is selected, an **Auto Layout** accordion should allow setting direction, gap, padding, and alignment distribution. | **High** |
| **3.2** | **Constraints & Resizing Missing** | No constraints box (Left, Right, Center, Top, Bottom, Scale, Hug contents, Fill container). | Responsive constraints must allow pinning elements to frame edges during parent resizing. | **High** |
| **3.3** | **Effects Panel Missing** | Cannot add Drop Shadow, Inner Shadow, Layer Blur, or Background Blur. | An **Effects** section with `+` button to add and configure blur radius, spread, color, and offset `(X, Y)`. | **Medium** |
| **3.4** | **Stroke Settings Limited** | Stroke only shows color and thickness; missing stroke alignment (Inside, Center, Outside) and dash settings. | Full stroke popover with alignment options and cap styles. | **Medium** |
| **3.5** | **Export Capabilities** | No multi-scale image export (1x, 2x, 3x PNG, SVG, PDF). | Export section with scale selector and instant client-side canvas rasterization download. | **Medium** |

---

### 4. Canvas Navigation & Hotkeys

| # | Feature / Area | Observed Problem | Expected Figma / OpenPencil Behavior | Severity |
|---|---|---|---|---|
| **4.1** | **Pan & Zoom Shortcuts** | `Space + Drag` pan or `Ctrl + Wheel` zoom can conflict with default browser scrolling. | Canvas viewport must intercept `Space + MouseDrag` for pan, `Ctrl/Cmd + Wheel` for smooth zoom (10% - 3200%), and `Shift + 1` to zoom to fit. | **High** |
| **4.2** | **Multi-Node Rubberband Box** | Dragging on empty canvas space does not draw a rubberband selection marquee to select multiple nodes. | Marquee selection must calculate 2D bounding-box intersections and multi-select intersecting nodes. | **High** |
| **4.3** | **Nudge Hotkeys** | Arrow keys and `Shift + Arrow keys` (10px nudge) not consistently focused on active selection. | Arrow keys move selected nodes by 1px (or `Shift + Arrow` by 10px). | **Medium** |

---

### 5. Remediation Plan & Execution Priority

1. **Fix Coordinate System & Frame Clipping** (`Critical`):
   - Wrap frame rendering in SVG/Canvas `<g>` with relative translation and CSS/SVG `clip-path` or `overflow: hidden`.
2. **Replace Placeholder Blocks with Rich Visual Elements** (`High`):
   - Render actual navigation icons, typography, avatars with image placeholders/gradients, and styled inputs.
3. **Synchronize Group / Frame Dragging** (`Critical`):
   - Ensure moving parent frames automatically shifts relative child coordinates without detachment.
4. **Expand Inspector with Auto-Layout & Effects** (`High`):
   - Add Auto-Layout toggles, Constraints, Drop Shadow effects, and Export triggers to `PropertyInspector.tsx`.
5. **Standardize Navigation & Toolbar** (`Medium`):
   - Switch "File" tab label to "Layers", unify top menu bar.
