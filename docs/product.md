# Product

## Overview
AI Manager (`dbci`) is a local-first database CI/CD, schema validation, and context management developer platform.

## Core Value Prop
Automates database migrations, AST-based flow validations, QA diagnostics, and schema health audits with offline SQLite/sql.js capabilities.

## Target User(s)
Full-stack engineers and backend developers building data-driven applications who need deterministic schema checks and AI-assisted context generation.

## Scope Boundaries
- Not a live production cloud DB host.
- Focuses on local developer tooling, CI validation passes, and AST analysis.
