# Product

## Overview
AI Manager (`dbci`) is a local-first database CI/CD, schema validation, and context management developer platform.

## Core Value Prop
Automates database migrations, AST-based flow validations, QA diagnostics, and schema health audits with offline SQLite/sql.js capabilities. Includes an AI-powered UI design studio featuring structured semantic layout generation, custom React canvas with progressive placement animations, and native Figma-compatible `.fig` file export via OpenPencil's headless core engine.

## Target User(s)
Full-stack engineers and backend developers building data-driven applications who need deterministic schema checks, AI-assisted context generation, and fast UI/screen prototyping with native `.fig` file export.

## Scope Boundaries
- Not a live production cloud DB host.
- Focuses on local developer tooling, CI validation passes, AST analysis, and local design file workflows (native `.fig` export via OpenPencil headless engine without requiring heavy external Docker services).
